# Clayton's resume

This is just where I keep my most recent resume.
I do not update this often.
If you really want to know what I've been up to, look at my [CV](https://claytonwramsey.com/cv).

## Building

I use [Typst](https://typst.app) to compile my resume.
If you have Typst installed on your system, you can compile the resume as follows:

```sh
typst compile resume.typ
```
